Use immutable evidence

Raw GitHub evidence must pin a 40-character commit. IPFS gateways must use a content identifier. The SHA-256 is calculated from the exact bytes validators fetch.

A proof records what the evidence supports. It does not authenticate an agent identity or settle a Base certificate.
