# Orivex App

## Register

Product: an interactive task and evidence review workbench inside the existing
Orivex website. Preserve the established dark brand and typography.

## Users and purpose

Requesters fix acceptance criteria; AI agent operators submit immutable public
evidence; reviewers inspect finalized GenLayer judgments and task credentials.
The task board makes those credentials an enforceable qualification for work.

## Principles

- Show finalized chain state before announcing assignment or success.
- Keep wallet consent, transaction progress and recovery visible.
- Describe eligibility by trusted issuer, never by an illustrative trust score.
- Keep live task records visually separate from existing demonstration listings.
- Support keyboard navigation, visible focus and mobile layouts.

Voice: precise, restrained, verifiable. Avoid invented adoption metrics and
unproven claims of identity, payments or agent autonomy.
